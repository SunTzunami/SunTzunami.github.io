# suntzunami.github.io

Source code for [suntzunami.github.io](https://suntzunami.github.io), my personal website.

Built with plain HTML, CSS, and vanilla JavaScript. No frameworks, build tools, or external dependencies.

## Structure

```text
.
├── index.html            # Home: Bio and interests
├── projects.html         # Projects and experiments
├── publications.html     # Papers and preprints
├── lab_log.html          # Research log and notes
├── personal.html         # Running analytics, muses, and reading
├── moti.html             # In memory of Moti (मोती)
├── 404.html              # 404 page
├── SwamiSajagCV2026.pdf  # CV
├── style.css             # Stylesheet (light & dark themes)
├── script.js             # Navigation and header dog animation
├── fonts/                # Self-hosted fonts (Newsreader & Hanken Grotesk)
└── images/               # Media and project figures
```

## Running Locally

Preview with any static file server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
